# The Dynamic Linker

- Use the LD mark from the neighboring vaults' `include/ld.png`. Its bundled vector is `yhwh/etc/assets/ld.svg`; keep the two open corners and the original proportions. The palette comes from `We The Nameless/.obsidian/snippets/ld.css`: dark `#2f383e`, light `#eeeeee`.
- Place marks at identity surfaces: the desktop title bar, welcome screen, About views, and review app branding. Keep documents, editor controls and terminal content clear. Decorative marks are hidden from assistive technology and inherit the interface's text color.
- Desktop launchers use circular artwork with transparent corners. `make install` uses the drawing from `include/yhwh-icons/yhwh-icon-we-third-mountain.png`; `make develop` uses the Paleo-Hebrew lettering from `yhwh-profile-pic-paleo-1.png`, arranged visually as `𐤄 𐤉` above `𐤄 𐤅`. The prepared artwork is bundled in `yhwh/etc/assets/icon-source.png` and `icon-development-source.png`.
- Desktop entries reference self-contained SVGs; Electron uses matching PNGs. Android and iOS inherit the installed mountain artwork. Android's adaptive foreground fits its safe area; iOS has an opaque background for the system's own mask. The LD mark remains the in-app identity mark. Builds must not depend on fonts, another vault, network access, or ImageMagick.
- After changing the bundled artwork, regenerate the checked-in exports with `node yhwh/bin/icons.cjs` (requires ImageMagick). Normal builds copy desktop SVGs into the packaged `etc/desktop` tree. Rerunning `make develop` or `make install` refreshes the corresponding desktop launcher and icon cache while preserving manually modified desktop files.
