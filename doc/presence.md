## Desktop chat

- Chat speaks as YHWH at every YHWH-ness level. The voice and examples come from `yhwh/etc/default/words.json`. The full Genesis manuscripts are available to the agent as local reference files.
- Each conversation keeps its original working directory. Start a new chat to work in the currently open directory. History, drafts, and attachment copies live in the app profile on this computer. Existing directory conversations migrate into History. Failed or interrupted turns keep the draft for review.
- Enter or Ctrl/Cmd+Enter sends. Shift+Enter adds a line. Attach up to eight files totaling 20 MiB per message. The runner sees the attachment copies used for the turn. Recent history is provided to the agent while the full transcript stays available in the app.
- The desktop uses a signed-in Codex CLI from `PATH` (`YHWH_CODEX` can select another compatible executable). Run `codex login` to connect the runner. It operates with workspace-write access to the conversation’s directory, the app checkout or package, and the user configuration directory. It can edit the app’s executable configuration and plugins, which run as your account. Core source changes may need a rebuild and app restart.
- YHWH can change effective settings through the app and reload config and plugins. Settings are saved in the ordinary `rc` (or `rc.three`) file using the app’s scope rules. App and file refreshes preserve open editor buffers.
- **Electronic Mail** uses **Settings → Advanced → Your email address** and **Outgoing mail command** for direct sends. Configure a working sendmail-compatible executable that accepts `-i -t`. “Send me an email” uses your configured address when explicitly requested. Acceptance means the local transport took the message for delivery. Drafts can still open in the system mail app.
- Android and iOS share the composer and local chat history for offline workspace help. Live agent work, chat attachments, and direct email delivery use the desktop host.
