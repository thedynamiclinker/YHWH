# Declarative descriptions

These documents describe the interfaces and enduring properties of YHWH.
Older feature specifications include desired behavior beyond the implemented
subset; implementation and tests establish the current state.

- [[mk-yhwh]] describes the default files/editor/shell interface.
- [[mk-yhwh-three]] adds the spatial interface.
- [[mk-yhwh-obsidian]] describes the plugin and its Obsidian constraints.
- [[mk-the-workflow]] describes executable English and human acceptance.

See [doc/README.md](../README.md) for the workflow, archive conventions and Git
commit format. Paths are relative to the vault root. Application architecture,
installation and configuration are documented in [yhwh/README.md](../../yhwh/README.md).
