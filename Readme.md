Run `make` to build and open the default app.

Run `make help` for more info.

Run the workflow with these commands, one at a time.

```sh
yhwh todo       # adds a todo item to the Board
yhwh begin      # begin: agent makes rough draft & questions
yhwh review     # call human to review & answer questions
yhwh run        # 
yhwh add
yhwh commit
```

Everything needed by the application lives in [yhwh/](yhwh/README.md).
The surrounding vault holds human work.
