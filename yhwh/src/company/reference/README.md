# Literary sources

`we-the-nameless/01-genesis/` contains the source text behind the literary
persona. The app bundles selected evidence and chapter references, and does not
require the manuscript directory at runtime.

Copied illustrations and typesetting caches are untracked. The original book
remains the authority for publishing those assets. This repository does not
build it. External company snapshots, migration inventories and project-specific
prompts are no longer part of the repository.
