# Interface

- Text is comfortably readable throughout the app.
- The initial interface is sleek, elegant, minimal, and familiar to Obsidian users. Settings use a minimal Obsidian-style interface rather than a collection of text inputs.
- The “Help from a higher power” dialog presents only God and Man. Other choices are hidden easter eggs, discoverable without overwhelming the interface.
- Files enters a directory on single click, Enter, or Right. Left goes up. The chevron unfolds a directory and modified clicks select rows. **Double-click directories** restores the two-click opening gesture.
- Files offers `un` with `new`, `cd`, `go`, and `ls`, alongside ordinary directory creation. `un cd` enters a universe and sets `@` while preserving `/`. `un go` can open a marked directory as a folder root on desktop, Shaddai, Android and iOS. On Linux it can also launch a Bubblewrap guest or an explicit system `chroot` using sudo when needed. Each mode opens a separate tab. Android and iOS create bundled starter universes in app storage.
- A prompt-like banner shows `.` (cwd), `@` (cwat), and `/` (root). The file manager has separate navigation and assignment controls. `@` starts at each tab’s opening directory and setting it preserves both `.` and `/`. The `@` setter runs directly by default, with a **Confirm cwat** setting. Setting `/` offers the same modes as `un go` for any directory. `cwat`, `@-set`, and `@-get` address the invoking tab.
- The Initial exposes `--prefix`, `bin`, `lib`, `etc`, `etc/profile`, and `PATH`. Desktop and Shaddai run ordinary Bash or Zsh startup, functions, aliases, and executable programs in the tab shell. Relative layout values follow `@`, and absolute paths stay fixed. A shell profile can opt in to sourcing a file relative to each new working directory on `cd`. Android and iOS edit ordinary files within app storage and run in-app commands through the Initial.
- The unchanged New World Shell prompt has a run ledger. A repeat first asks multiple-choice questions with a free-text option, then passes the answers forward with the original request.
- Folder rows have a desktop-style context menu and a touch equivalent. The menu can set `@` and discover actions from ordinary files in the app’s folder-menu configuration directory. A bundled Hello world action demonstrates the format.
- Ctrl+L always clears the terminal when it is visible. It may focus the file-manager title bar only when the terminal is closed.
- Settings and keyboard-shortcut controls belong to YHWH's visual language; the settings icon avoids an Apple-like appearance, and a bare question mark does not represent key combinations.
- The app is a productive supernatural IDE, terminal++, and desktop environment for every directory on the system. Navigation and file management span the whole system without an inherent vault boundary.
- The text editor uses the vault's Everforest palette, Noto type, and the six LD heading colors in Markdown Live Preview, Source, and Reading. Markdown editing uses familiar formatting and line-movement shortcuts while preserving the original source and undo history.
- Text opens with automatic syntax highlighting from the system MIME type, filename, and file contents. The lower-right language picker defaults to Auto. Manual highlighting keeps the document text and undo history intact and reveals **Why?**. Saving an explanation appends the user's text to a local, language-independent tab-separated log. Explicitly remembered rules live in a plain-text prefix configuration file. See [Interface](../../doc/interface.md).
