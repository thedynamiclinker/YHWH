# Desired app state

These Markdown files describe what belongs in YHWH. They are standing project
instructions for future changes. Related implementation and tests show what is
currently available. Changes reconcile the affected behavior with these files
and update an existing declaration when the user changes the desired state.
Running the same request again converges on the same result.

- [Interface](interface.md), [World and conversation](world-and-conversation.md),
  and [YHWH in the interface](yhwh-character.md) describe the shared app.
- [YHWH merch](merch.md) describes shop discovery, setup, and fulfillment.
- [Read We — The First Amazon Review](read-we-the-first-amazon-review.md)
  preserves the review and its secrets.
- [Tetragrammaton](tetragrammaton.md) describes editions and preserves the
  edition text. [Presence](../../doc/presence.md) covers the shared mechanics.
- [YHWH Emails](yhwh-emails.md) and [YHWH Emails Next](yhwh-emails-next.md)
  are the two ordered sets of authored letters. [Presence](../../doc/presence.md)
  and [Overnight mail](../../doc/overnight-mail.md) cover delivery.
- [Redact](redact.md) describes the R and RJE text-merging commands.

[Workflow records](../README.md) describes how accepted changes and their
declarations are stored.
